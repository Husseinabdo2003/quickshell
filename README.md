# Quickshell Setup Structure

## Root

- `shell.qml`
  - Loads the whole Quickshell setup.
  - Starts the top bar, power menu, OSDs, notifications, wallpaper picker, and overview.
  - Runs startup wallpaper restore.

## Theme

- `theme/Theme.qml`
  - Static layout values: bar height, spacing, radius, font size.
- `theme/WalTheme.qml`
  - Generated by pywal/update-theme script.
  - Contains dynamic colors from wallpaper.
- `theme/Animations.qml`
  - Shared animation durations.

## Components

Reusable UI building blocks:

- `Card.qml`
  - Generic rounded container.
- `PopupPanel.qml`
  - Animated popup panel.
- `BarPill.qml`
  - Base top-bar pill.
- `BarActionPill.qml`
  - Icon-only clickable bar pill.
- `BarInfoPill.qml`
  - Text/info bar pill.
- `BarMediaPill.qml`
  - Media player bar pill.
- `ActionButton.qml`
  - Text button for panels.
- `IconButton.qml`
  - Small icon button.
- `Slider.qml`
  - OSD slider.
- `SearchBox.qml`
  - Search input.
- `FormInput.qml`
  - Form input.
- `Badge.qml`
  - Small pill badge.
- `Divider.qml`
  - Divider line.
- `TitleText.qml`
  - Main text style.
- `HeadingText.qml`
  - Heading text style.
- `MetaText.qml`
  - Muted/meta text style.
- `AccentStrip.qml`
  - Small vertical accent strip.

## Modules

### Bar

- `modules/bar/TopBar.qml`
  - Main top bar window.
- `LeftSection.qml`
  - Workspaces and tray.
- `CenterSection.qml`
  - Clock and media.
- `RightSection.qml`
  - System widgets.

### Dashboard

- `Dashboard.qml`
  - Dashboard popup window.
- `DashboardState.qml`
  - Active category and category helper logic.
- `DashboardActions.qml`
  - Add/remove item script execution.
- `DashboardAddPopup.qml`
  - Add item form.
- `DashboardList.qml`
  - Item list.
- `UniCard.qml`
  - Dashboard item card.

### Wallpaper Picker

- `WallpaperPicker.qml`
  - Wallpaper picker window/state.
- `WallpaperActions.qml`
  - List/apply/restore wallpaper logic.
- `WallpaperList.qml`
  - Horizontal wallpaper list.
- `WallpaperCard.qml`
  - Wallpaper image card.
- `WallpaperHeader.qml`
  - Header/title/count/close.
- `WallpaperScrollbar.qml`
  - Horizontal scroll indicator.

### Notifications

- `NotificationPopup.qml`
  - Popup notifications.
- `NotificationCenter.qml`
  - Notification center panel.
- `NotificationGroupCard.qml`
  - Single or stacked app notification group.
- `NotificationCard.qml`
  - Reusable notification card with icon support.

### OSD

- `VolumeOSD.qml`
  - Volume OSD.
- `BrightnessOSD.qml`
  - Brightness OSD.
- `LockOSD.qml`
  - Caps/Num lock OSD.
- `OsdPanel.qml`
  - Shared OSD visual panel.

### Overview

- `WorkspaceOverview.qml`
  - Full overview window.
- `WorkspacePreview.qml`
  - Workspace tile.
- `WindowPreview.qml`
  - Window preview tile.
- `OverviewConfig.qml`
  - Special workspace config.

### Power Menu

- `PowerMenu.qml`
  - Power menu window.
- `PowerAction.qml`
  - Lock/suspend/reboot/shutdown card.

## Services

- `ShellState.qml`
  - Shared open/close state.
- `DashboardData.qml`
  - Dashboard item loading.
- `NotificationService.qml`
  - Notification server, grouping, icons, dismiss/clear.
- `HyprlandService.qml`
  - Hyprland helpers if used.

qs ipc call wallpaperPicker toggle
qs ipc call wallpaperPicker restore
qs ipc call notificationCenter toggle
qs ipc call notificationCenter clear
qs ipc call powerMenu toggle

qs ipc call volumeOsd raise
qs ipc call volumeOsd lower
qs ipc call volumeOsd toggleMute
qs ipc call brightnessOsd raise

qs ipc call lockOsd caps
qs ipc call lockOsd num
